# Вахта Калькулятор (MVP 0.5)

Android-проект калькулятора реального дохода по вахтовым вакансиям.

## Интерфейс 0.5

Интерфейс перестроен по утверждённому тёмному макету:

- постоянная нижняя навигация из четырёх разделов: «Калькулятор», «Сравнение», «Чеки», «Настройки»;
- шапка «Вахта Калькулятор» и переключатель «Вакансия 1 / Вакансия 2»;
- компактные тёмные карточки с тонкой обводкой;
- фон `#121212`, оранжевый акцент `#FF6B00`, денежные значения зелёные;
- расходы всегда открыты до расчёта: дорога, питание, «Спецодежда / форма», штрафы;
- отдельный экран результата с крупным чистым доходом, доходом в день и реальным доходом в час;
- бесплатный экран сравнения двух вакансий с итоговым блоком и краткой таблицей;
- отдельный раздел «Чеки» для сохранённых расчётов;
- отдельный раздел «Настройки» с двумя независимыми покупками и восстановлением покупок;
- рекламный блок оформлен как место под Яндекс Рекламу;
- в пользовательском интерфейсе нет каналов, подписок и внешних переходов.

## Покупки

Подготовлены две независимые покупки:

1. «Отключить рекламу — 99 ₽» — должна скрывать рекламный блок.
2. «Сохранить расчет в чеки — 99 ₽» — должна разблокировать сохранение расчётов.

В исходной сборке реальный платёжный SDK не подключён и списание денег не имитируется. Для выпуска приложения нужно подключить биллинг выбранного магазина и связать два продукта с независимыми правами `REMOVE_ADS` и `SAVE_TO_CHECKS`.

## Расчёт

На основном экране ставка задаётся за день/смену, длительность — в днях, график — в часах в день. Расчётный движок остаётся вынесенным в отдельный domain-модуль. `tools/EngineSelfTest.kt` содержит 10 контрольных сценариев; математическая часть не изменена.

## Открытие проекта

Откройте папку `VahtaCalculatorMVP` в Android Studio, выполните Gradle Sync и запустите приложение на устройстве или эмуляторе. Проект использует Android SDK API 37, Java 17 и Jetpack Compose.
